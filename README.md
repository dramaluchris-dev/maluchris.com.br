# MaluChris — Landing Page estática

Pacote independente com:

- `index.html`
- CSS compilado em `assets/`
- JavaScript compilado em `assets/`
- Assets visuais originais em `assets/hero.jpg`, `assets/process.jpg` e `assets/gift.jpg`

O botão do WhatsApp já está configurado para o número da MaluChris.
